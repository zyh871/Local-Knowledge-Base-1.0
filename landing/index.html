Why Desktop

为什么要把知识库搬回本地

网页版需要你自己准备服务器、数据库与运行时。桌面版把这些打包成一个安装包—— 更重要的是，数据从此留在你自己的磁盘上。

数据落在你自己的磁盘

向量库、会话记录、生成的文件都存在本机目录里。没有云端副本， 也不需要为了查一份内部手册先把文件传到别人的服务器上。

安装即用，不必自建服务

不需要装 Python、Node 或 Redis，也不用配反向代理。 下载、安装、填一次模型密钥，就能开始导入文档提问。

直接读写本地文件

把项目目录绑定为工作区，工作流可以读取其中的文档、 把结果写成 Markdown 落到磁盘，而不是让你手动复制粘贴。

一个窗口装下全部

对话、工作流、AI 创作、团队空间、模型广场都在同一个应用里， 不必在多个浏览器标签页之间来回切换。

数据边界，说清楚比说好听重要。 知识库原文、对话记录与生成结果只存在你的机器上。 但模型推理仍然需要算力：被检索命中并送入提示词的文本片段，会随请求发往 你自己配置的模型端点——可以是云厂商 API，也可以是完全内网的自建服务。 换端点只改一处配置，不需要迁移数据。

Desktop vs Web

和自建网页版的区别

功能一致，差别在谁维护运行时、数据放在哪、以及文件能不能直接读写。

本地文件 需要手动上传 可绑定目录，直接读、直接写回
模型配置 改环境变量后重启 界面内切换，按请求生效

关于离线使用

客户端本身不需要联网即可启动，文档管理与检索也在本机完成。 但只要模型走的是云端 API，提问时就必须有网。

  • 把模型端点指向内网或本机的 OpenAI 兼容服务，即可全程不出外网
  • 文档解析、向量化调用的是你配置的嵌入模型，不额外上传原文
  • 更换嵌入模型后需要重建向量库，界面上有对应操作
FAQ

常见问题

桌面版和网页版是两套东西吗？

同一套后端与同一套界面，桌面版把运行时、依赖与服务进程一起打包了。数据格式一致，本机目录可以直接备份或迁移。

我的文档会被上传到服务器吗？

不会整份上传。知识库原文、对话记录、生成结果都写在你本机的目录里。

提问时，只有被检索命中、需要送进提示词的那几段文本会随请求发给你配置的模型端点。如果这个端点是内网服务，文本就不会离开你的网络。

不联网能用吗？

客户端启动、文档管理、检索都在本机完成，不依赖外网。但生成答案必须调用模型，所以要么有网，要么把模型端点指向内网 / 本机上的 OpenAI 兼容服务。

怎么用本地模型，不填任何密钥？

装好 Ollama 之后，运行客户端目录里的 检测本地模型.cmd（或 python tools/ollama_bootstrap.py）。它会依次检查三件事：

磁盘上有没有 ollama 程序、本机 11434 端口上的服务在不在、以及服务里有没有可对话的模型（纯向量模型不算）。三项都过，就直接写好配置，启动后用的就是本地模型，请求不会离开这台机器。

任何一项没过，它会把差的那一步说清楚：没装就给出下载地址和一条 ollama pull 命令（按内存推荐模型大小）；装了但服务没起，就给出启动命令；都没有也可以直接改用云端 API。

必须用某一家的模型吗？

不必须。模型广场里并列了十家厂商的常用型号，也可以新增自定义端点，只要接口符合 OpenAI 规范（/chat/completions、/embeddings）就能接。

注意：更换嵌入模型后向量维度可能变化，需要重建向量库。

支持哪些文档格式？

PDF、Word（.docx）、Markdown 与纯文本。扫描件需要先做 OCR 再导入，客户端不内置 OCR。单个文件过大时会按段落切分，切分结果可以在文档详情里查看。

数据存在哪里？怎么备份或迁移？

都在应用的数据目录下：向量库在 chroma_db/，会话与业务数据是 data/ 下的几个 SQLite 文件，创作素材在 data/creations/。

备份就是复制这几个目录；迁移到新机器时整份拷过去即可，不需要导出导入流程。

卸载会不会把知识库一起删掉？

卸载程序只移除应用本体，数据目录默认保留。确认不再需要时，手动删除该目录即可彻底清理。

有 Linux 版吗？能自己编译吗？

目前没有原生安装包。下载通用包解压后，用 python3 deploy/serve.py 起一个本地服务器即可访问，只依赖 Python 标准库。
